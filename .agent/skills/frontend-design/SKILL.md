# Frontend Design Skill

## Propósito
Asegurar que todas las pantallas y componentes mantengan un acabado visual premium, artesanal y lúdico, evitando aspectos genéricos de plantillas por defecto.

## Principios Estéticos
1. **Paleta Pastel Armoniosa**: Fondos suaves combinados con tipografía oscura de alta legibilidad (`#111111`).
2. **Micro-interacciones**: Transiciones suaves en hover (elevación `-2px` a `-4px`, sombras difuminadas, rotación de iconos).
3. **Consistencia Visual**: Elementos repetidos (botones, inputs, tarjetas, badges) deben compartir proporciones y estilo en todas las páginas.
