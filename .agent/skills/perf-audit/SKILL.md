# Performance Audit Skill

## Propósito
Optimizar tiempos de carga, métricas Core Web Vitals y peso de la página, asegurando que la experiencia en dispositivos móviles sea instantánea y fluida.

## Objetivos Clave
- **LCP (Largest Contentful Paint)**: < 2.5 s
- **CLS (Cumulative Layout Shift)**: < 0.1
- **INP (Interaction to Next Paint)**: < 200 ms
- **Optimización de Recursos**:
  - Imágenes con dimensiones explícitas (`aspect-ratio` o `width`/`height`).
  - Formatos ligeros WebP/PNG optimizado.
  - Peso total del HTML inicial controlado (< 100 KB en portada).
